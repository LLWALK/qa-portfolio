# QA Portfolio

Hi, I'm Liam, an aspiring QA tester learning manual testing and test automation.

I'm hands-on with tech: I build and troubleshoot my own PC and VR setups (full-body tracking, face tracking), and I'm now applying that same curiosity to finding and documenting software bugs.

## What's here

### 🐞 Bug reports (`/bug-reports`)
Real bugs I've found on live websites and apps, written up with steps to reproduce, expected vs actual results, and severity.

### 🤖 Automation (`/automation`)
Browser automation scripts written in Python with Playwright.

- `first.py` - opens a site, reads the page title and takes a screenshot
- `price.py` - pulls a product's price from a store page using its structured data, with a fallback method

## Currently learning
- Python + Playwright
- Test case design and bug reporting
- Working towards the ISTQB Foundation certification

## Tools
Python · Playwright · Git/GitHub

- `price_watch.py` - tracks a product's price over time, saves history to CSV and reports drops/rises. Tested all four outcomes using manipulated test data.
- `bug_hunter.py` - scans a web page for console errors, failed requests, broken images, missing alt text and duplicated title text. Tuned to filter out false positives like tracking pixels.
